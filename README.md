**Интерактивные обои для рабочего стола**.

---

## 🚀 Как запустить

1. Скачайте папку с проектом на свой компьютер.
2. Откройте файл `index.html` в любом современном браузере.
3. Поводите мышкой — глаза будут следить за курсором!

### Установка на рабочий стол
Чтобы сделать глаза своими обоями:
1. Установите программу Lively Wallpaper.
2. Откройте Lively, нажмите «Добавить обои» и укажите путь к вашему `index.html`.
3. В настройках обоев включите **«Взаимодействие с мышью»** (Input), чтобы глаза реагировали на курсор.

---

## 🛠 Технологии

- **HTML5** — структура слоев.
- **CSS3** — позиционирование.
- **JavaScript** — математика движения (нахождение вектора, нормализация, синусы и косинусы).

---

## 📐 Как это работает (Математика)

1. Находим центр глаза и координаты курсора.
2. Вычисляем катеты (разницу координат) и гипотенузу (расстояние).
3. Делим катеты на гипотенузу, чтобы получить **единичный вектор** (направление).
4. Умножаем на максимальное смещение, чтобы зрачок не вылезал за пределы века.
